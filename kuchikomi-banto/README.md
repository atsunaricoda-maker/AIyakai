# クチコミ番頭

Googleクチコミへの返信文を、AIが10秒で3案つくるWebサービス。

日本の中小店舗オーナー（飲食・美容・整体・歯科・工務店・学習塾など）向けの、
月額¥2,980からのサブスクリプション型SaaSです。

- **本体**: Cloudflare Workers + Hono + D1
- **生成**: Claude API（既定 `claude-opus-5`）
- **決済**: Stripe Checkout（サブスクリプション、14日間無料トライアル）
- **メール**: Resend（任意。未設定でも動作する）

---

## なぜこの形なのか

Googleビジネスプロフィールとの API 連携をあえて行っていません。連携には Google 側の
審査が必要で、リリースまでに数週間かかります。「クチコミ本文を貼り付ける」方式にすることで、
**審査ゼロ・当日から使える**状態を優先しました。運用コストもほぼゼロに抑えられます。

差別化は次の3点です。

1. **店舗プロフィールの自動反映** — 業種・こだわり・NGワード・署名を一度登録すれば、以降すべての返信に反映される
2. **低評価への型** — 「お詫び → 事実を断定しない受け止め → 改善 → 個別連絡への誘導」を自動で組み立てる
3. **リスク検知** — 誹謗中傷や事実無根のクチコミを検知し、「返信より先に削除申請を検討すべき」と助言する

## セットアップ（ローカル）

```bash
npm install
cp .dev.vars.example .dev.vars   # ANTHROPIC_API_KEY を記入
npm run db:migrate:local
npm run dev                       # http://127.0.0.1:8787
```

Stripe を設定していない場合、`/signup` は決済をスキップしてトライアルを開始します
（公開前の動作確認用）。

## 主なエンドポイント

| パス | メソッド | 説明 |
|------|---------|------|
| `/api/generate` | POST | 返信案の生成。未ログインなら無料お試し枠（3件）で動作 |
| `/api/me` | GET | アカウント・利用量・店舗一覧 |
| `/api/shops` | POST | 店舗プロフィール作成 |
| `/api/shops/:id` | PUT / DELETE | 店舗プロフィール更新・削除 |
| `/api/replies` | GET | 生成履歴（直近50件） |
| `/billing/checkout` | POST | Stripe Checkout セッション作成 |
| `/billing/portal` | POST | 解約・支払方法変更のポータル |
| `/api/stripe/webhook` | POST | Stripe Webhook（署名検証・冪等処理あり） |
| `/api/admin/stats` | GET | 契約数・MRR・トークン消費（`x-admin-token` 必須） |

## モデルとコスト

既定は `claude-opus-5`。`wrangler.jsonc` の `vars.ANTHROPIC_MODEL` で変更できます。
生成1件あたりの実測原価は `/api/admin/stats` のトークン合計から算出できます
（計算式は GO-LIVE.md 参照）。システムプロンプトには prompt caching を効かせているため、
2件目以降の入力コストは大きく下がります。

コストを下げたい場合の調整順は次のとおりです。

1. `vars` に `ANTHROPIC_EFFORT` を追加して `low` にする（既定は `medium`）
2. それでも高い場合にモデルを変更する

## 不正利用対策

- 未ログインの無料枠は Cookie（通算3件）と IP ハッシュ（**1日60件・日次リセット**）の両方でカウントし、
  Cookie 削除による回避を抑えています。IP側を日次にしているのは、会場Wi-Fiや携帯キャリアのCGNATで
  無関係な多数の利用者が同じIPを共有するためです（恒久ブロックを避ける）。上限値は
  `vars.FREE_TRIAL_IP_LIMIT` で変更できます
- クチコミ本文は2000文字上限
- Stripe Webhook は署名検証 + イベントID による冪等処理
- ログインコード・セッショントークンはハッシュのみ保存（平文は保持しない）
