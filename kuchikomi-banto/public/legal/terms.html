第1条（適用）

  1. 本規約は、本サービスの利用に関する当社と利用者との間の一切の関係に適用されます。
  2. 当社が本サービス上で掲載する利用上のご案内、ヘルプ、ガイドライン等（以下「個別規定」といいます）は、本規約の一部を構成します。
  3. 本規約と個別規定の内容が異なる場合には、個別規定の定めが優先して適用されます。
  4. 利用者は、本サービスを利用した時点で、本規約に同意したものとみなされます。

第2条（定義）

  1. 「利用者」とは、本規約に同意して本サービスを利用する個人または法人をいいます。
  2. 「登録利用者」とは、第4条に基づきアカウント登録を完了した利用者をいいます。
  3. 「有料プラン」とは、ライトプランおよびスタンダードプランその他当社が定める有償のプランをいいます。
  4. 「入力情報」とは、利用者が本サービスに入力または登録した情報（クチコミ本文、星評価、店舗プロフィール等）をいいます。
  5. 「生成物」とは、入力情報に基づき本サービスが出力した返信文案その他の文章をいいます。

第3条（本サービスの内容）

  1. 本サービスは、利用者が入力したクチコミ本文および星評価、ならびに登録された店舗プロフィールをもとに、返信文の案を複数提示するサービスです。
  2. 本サービスは、返信文の案を作成する支援ツールであり、Googleビジネスプロフィールへの投稿を代行するものではありません。生成物の投稿は、利用者ご自身が行うものとします。
  3. 本サービスは、Google LLC その他の第三者と提携・提供元関係にあるものではなく、当社は同社の公式サービスではありません。
  4. 本サービスには、誹謗中傷や事実無根と疑われるクチコミを検知して注意を促す機能が含まれますが、これは判断の参考となる情報を提供するにとどまり、削除申請の可否や結果を保証するものではありません。
  5. 当社は、本サービスの利用により、検索順位、地図検索での表示順位、集客、売上その他の成果が向上することを保証しません。

第4条（登録）

  1. 本サービスの有料プランの利用を希望する者は、本規約に同意のうえ、当社所定の方法により登録を申請するものとします。
  2. 当社は、申請者が次のいずれかに該当すると判断した場合、登録を承認しないことがあり、その理由について開示する義務を負いません。
    1. 登録事項に虚偽、誤記または記載漏れがあった場合
    2. 過去に本規約違反等により、利用停止または登録抹消の措置を受けたことがある場合
    3. 反社会的勢力等（第20条に定義します）に該当し、または関与していると当社が判断した場合
    4. その他、当社が登録を適当でないと判断した場合
  3. 登録は、当社が承認の通知を行った時点で完了し、利用者と当社との間に本規約に基づく利用契約が成立します。
  4. 利用者は、登録事項に変更が生じた場合、遅滞なく当社所定の方法により変更手続を行うものとします。

第5条（アカウントの管理）

  1. 登録利用者は、自己の責任において、メールアドレスおよび当社が発行するログインコードを適切に管理するものとします。ログインコードが第三者に知られたおそれがある場合は、管理画面から速やかに再発行してください。
  2. 登録利用者は、いかなる場合も、アカウントを第三者に譲渡し、貸与し、または共有することはできません。ただし、同一の事業者に所属する従業者による利用は、この限りではありません。
  3. アカウントの管理不十分、使用上の過誤、第三者の使用等による損害の責任は、登録利用者が負うものとし、当社は一切の責任を負いません。ただし、当社の故意または重過失による場合を除きます。
  4. アカウントが第三者に不正に利用されていることが判明した場合、登録利用者は直ちに当社に通知し、当社の指示に従うものとします。

第6条（料金および支払方法）

  1. 有料プランの利用料金は、本サービス上に表示する金額（消費税込み）のとおりとします。
  2. 利用者は、当社が指定するクレジットカード決済（決済代行事業者：Stripe）により、利用料金を支払うものとします。
  3. 有料プランは月額の自動更新とし、無料トライアル終了日の翌日を初回課金日として、以後毎月同日に自動的に課金されます。該当日が存在しない月は、その月の末日を課金日とします。
  4. 各プランには、生成件数および登録可能な店舗数の上限があります。生成件数は暦月ごとに計算し、翌月の開始をもってリセットされます（集計は協定世界時を基準とするため、日本時間では毎月1日の午前9時ごろに切り替わります）。上限に達した場合、リセットまで生成機能をご利用いただけません。
  5. 決済に失敗した場合、当社は所定の回数・間隔で再試行を行い、なお決済ができないときは、本サービスの提供を停止し、または利用契約を解除することができます。
  6. 当社は、利用料金を改定することがあります。改定を行う場合は、改定日の30日前までに本サービス上または電子メールにより通知します。通知後、改定日以降も利用を継続した場合、改定後の料金に同意したものとみなします。
  7. 利用者が支払を遅滞した場合、年14.6%の割合による遅延損害金を申し受けることがあります。

第7条（無料お試しおよび無料トライアル）

  1. 当社は、登録不要でご利用いただける無料お試し（生成3件まで）を提供します。無料お試しには、本規約のうち性質上適用され得る条項が適用されます。
  2. 有料プランには、初回申込時に限り14日間の無料トライアル期間を設けます。トライアル期間中に解約した場合、利用料金は発生しません。
  3. 無料トライアルは、原則として1つの事業者につき1回限りとします。当社は、複数のアカウントを作成してトライアルを繰り返すなど、不正な利用と判断した場合、トライアルの提供を停止することができます。
  4. 無料お試しおよび無料トライアルの期間中は、機能の一部が制限される場合があります。

第8条（解約および返金）

  1. 登録利用者は、いつでも管理画面から解約の手続を行うことができます。
  2. 解約の手続を行った場合でも、すでに支払済みの期間の末日までは有料プランを利用でき、期間の満了をもって利用契約は終了します。
  3. 本サービスは、その性質上、日割りによる返金は行いません。月の途中で解約した場合も、当該期間の利用料金は返金されません。
  4. 前項にかかわらず、当社の責めに帰すべき事由により長時間にわたり本サービスを提供できなかった場合など、当社が特に必要と認めた場合には、個別に返金その他の対応を行うことがあります。
  5. 利用契約の終了後、当社はプライバシーポリシーに定める保存期間の経過をもって、登録情報および入力情報を削除します。必要なデータは、解約前に利用者ご自身で保存してください。
