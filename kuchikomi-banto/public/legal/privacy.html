第2条（取得する情報）

当社は、本サービスの提供にあたり、以下の情報を取得します。

  1. アカウント情報：メールアドレス、ログインコード（当社は元の値に復元できない形式に変換して保存します）、ご契約プランおよびアカウントの状態。
  2. 店舗プロフィール：店舗名、業種、店舗の特徴やこだわり、使用を避けたい表現（NGワード）、返信文の署名など、お客様が任意にご登録いただく情報。
  3. 入力されたクチコミ本文および生成結果：返信文の作成のためにお客様が貼り付けたクチコミの本文、星評価、クチコミ投稿者の表示名（お客様が任意にご入力いただいた場合）、および本サービスが生成した返信文案。
  4. 利用状況に関する情報：返信文の生成回数、生成日時、ご契約プラン、機能の利用履歴。
  5. 決済に関する情報：ご契約プラン、課金状況、決済の成否および決済識別子。クレジットカード番号、有効期限、セキュリティコードは決済代行事業者である Stripe が取得・保持し、当社はこれらを保持しません。
  6. アクセスログ等：IPアドレス、ユーザーエージェント（ブラウザ・OSの種類）、アクセス日時、参照元URL、閲覧ページ、エラー情報。
  7. Cookieおよび類似技術により取得される情報：ログイン状態の保持に用いる識別子、および登録不要の無料お試しの利用回数を管理するために端末へ発行する識別子（詳細は第8条）。
  8. 無料お試しの回数管理に用いる情報：前号の識別子に加え、同一の回線からの繰り返し利用を防ぐため、IPアドレスを元に戻せない形式へ変換した値と、その利用回数。
  9. お問い合わせ内容：お問い合わせの際にご記入いただいたメールアドレス、お名前、お問い合わせ本文。

お願い：クチコミ本文の入力欄には、返信の作成に必要のない情報（お客様ご自身や第三者の氏名・連絡先・病歴・信用情報など）を入力しないでください。やむを得ず第三者の情報が含まれる場合は、必要最小限にとどめてください。

第3条（利用目的）

当社は、取得した情報を以下の目的で利用します。

  1. 本サービスの提供、返信文案の生成、および店舗プロフィールの反映のため
  2. ご本人の認証、アカウントの管理、および不正利用の防止のため
  3. 利用料金の請求、決済処理、および課金状況の管理のため
  4. お問い合わせ、お申出への対応および本人確認のため
  5. 本サービスの保守、障害対応、不具合の原因調査および再発防止のため
  6. 利用規約に違反する行為への対応のため
  7. 本サービスの利用状況の分析、品質および生成精度の改善、新機能の開発のため（この目的で用いる場合、個人を識別できない形に加工した統計情報として取り扱います）
  8. 本サービスに関する重要なお知らせ（規約変更、料金改定、メンテナンス等）の通知のため
  9. 当社サービスに関する案内やご提案の送付のため（あらかじめご同意いただいた場合、または法令上許容される場合に限ります。受信は配信停止の手続きによりいつでも停止できます）

当社は、あらかじめご本人の同意を得ることなく、上記の利用目的の達成に必要な範囲を超えて個人情報を取り扱うことはありません。

第4条（クチコミ本文および生成結果の取扱い）

  1. お客様が入力したクチコミ本文および店舗プロフィールは、返信文案を生成する目的でのみ、Anthropic, PBC が提供する Claude API に送信されます。
  2. Anthropic 社が公表する商用利用向けの規約および方針では、API を通じて送信された入力および出力は、同社の生成モデルの学習には利用されないとされています。当社もお客様の入力内容を当社独自のモデルの学習に利用することはありません。
  3. 入力したクチコミ本文および生成結果は、お客様が過去の履歴を確認できるようにするため、当社のデータベースに保存されます。履歴は管理画面でご確認いただけます。個別の削除をご希望の場合は、第14条のお問い合わせ窓口までご連絡ください。速やかに削除いたします。
  4. 当社の従業者が入力内容を閲覧するのは、お客様からのお問い合わせ対応、障害調査、または法令に基づく必要がある場合に限られ、必要最小限の範囲にとどめます。

第5条（第三者提供）

当社は、以下のいずれかに該当する場合を除き、あらかじめご本人の同意を得ることなく、個人データを第三者に提供しません。

  1. 法令に基づく場合
  2. 人の生命、身体または財産の保護のために必要がある場合であって、ご本人の同意を得ることが困難であるとき
  3. 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、ご本人の同意を得ることが困難であるとき
  4. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、ご本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき
  5. 合併その他の事由による事業の承継に伴って個人データが提供される場合（この場合、承継後も本ポリシーと同等の取扱いを求めます）

なお、次条に定める委託先への提供は、法令上「第三者提供」には該当しません。

第6条（業務の委託・外部サービスの利用）

当社は、利用目的の達成に必要な範囲内で、個人データの取扱いの全部または一部を外部に委託しています。委託先に対しては、法令に基づき必要かつ適切な監督を行います。現在利用している主な外部サービスは以下のとおりです。

Cloudflare, Inc.

本サービスのアプリケーション実行基盤、データベース、CDN および通信の保護。

アカウント情報、店舗プロフィール、クチコミ本文、生成結果、アクセスログを同社の基盤上で保管・処理します。
Stripe, Inc.
（および同社グループ）

クレジットカード決済およびサブスクリプション管理。

メールアドレス、決済に必要なカード情報、課金履歴が同社に提供されます。カード番号等は同社が直接取得し、当社は保持しません。
Resend, Inc.

ログインコードのお知らせや重要なご連絡など、電子メールの配信。

お客様のメールアドレスおよびメール本文が同社の基盤を経由して送信されます。
Anthropic, PBC

返信文案の生成（Claude API）。

お客様が入力したクチコミ本文、星評価および店舗プロフィールが、返信文の生成のために同社の API へ送信されます。同社が公表する方針では、API 経由で送信されたデータは同社の生成モデルの学習には利用されないとされています。

上記のほか、メール配信やアクセス解析等のために外部サービスを利用する場合があります。委託先を変更した場合は、本ポリシーの改定によりお知らせします。各社における具体的な取扱いは、各社が公表するプライバシーポリシーもあわせてご確認ください。

第7条（外国にある第三者への提供／越境移転）

  1. 前条に記載の Cloudflare, Inc.、Stripe, Inc.、Resend, Inc. および Anthropic, PBC は、いずれもアメリカ合衆国に本拠を置く事業者であり、これらのサービスの利用に伴い、お客様の個人データが日本国外（主に米国。各社のインフラ構成により、その他の国のデータセンターを経由する場合があります）で保管または処理されることがあります。
  2. 移転先の国においては、日本の個人情報保護法と同一の水準の制度が整備されているとは限らず、政府機関による情報開示要求など、日本国内とは異なる制度が適用される可能性があります。
  3. 当社は、移転先の事業者との間で、個人データの適正な取扱いを確保するための契約上の措置（データ処理に関する条項の締結等）を講じ、その実施状況を定期的に確認します。
  4. 移転先の国の個人情報保護制度に関する情報について、詳細をお知りになりたい場合は、第14条の窓口までお問い合わせください。

第8条（Cookie等の利用）

  1. 本サービスは、ログイン状態の保持、セキュリティの確保（不正アクセス防止）、入力内容の一時保持、および登録不要の無料お試しの利用回数の管理のために Cookie および類似技術（ローカルストレージ等）を利用します。これらは本サービスの動作に必要なものです。
  2. 本サービスの改善のため、アクセス状況の統計的な把握を目的とした解析用の Cookie を利用する場合があります。これらの情報は、個人を直接識別しない形で利用します。
  3. お客様はブラウザの設定により Cookie の受け入れを拒否できますが、その場合ログインができないなど、本サービスの一部または全部をご利用いただけなくなることがあります。
  4. 当社は、広告配信を目的とした第三者による行動追跡型の Cookie を、本サービス内で利用していません（将来利用する場合は、本ポリシーを改定してお知らせします）。

第9条（保存期間）

  1. アカウント情報・店舗プロフィール：ご契約期間中および退会後90日間保存し、その後合理的な期間内に削除します（誤操作による退会からの復旧、および不正利用対策のため）。
  2. クチコミ本文および生成結果：お客様が管理画面から削除するまで、またはアカウント削除後90日間保存します。
  3. アクセスログ：取得から12か月を目安に削除します（障害調査および不正アクセス調査のため）。
  4. 取引・決済に関する記録：法令（法人税法、消費税法等）の定めに従い、必要な期間（原則として7年間）保存します。
  5. お問い合わせ内容：対応完了から3年間を目安に保存します。
  6. 無料お試し（登録不要）でご利用いただいた場合：入力されたクチコミ本文および生成結果は、サービスの品質確認および不正利用の防止のため、アカウントと紐づかない形で保存し、取得から90日間を目安に削除します。利用回数の管理に用いる識別子およびIPアドレスを変換した値は、取得から12か月を目安に削除します。

第10条（安全管理措置）

当社は、個人データの漏えい、滅失または毀損の防止その他の安全管理のため、次の措置を講じています。

  • 組織的措置：個人情報の取扱いに関する責任者の設置、取扱状況の記録および点検。
  • 人的措置：従業者に対する教育、および秘密保持義務の設定。
  • 物理的・技術的措置：通信の暗号化（TLS）、ログインコードおよびセッション識別子の不可逆変換による保存、アクセス権限の必要最小限化、認証基盤による管理画面の保護、および外部からの不正アクセス対策。
  • 委託先の監督：委託先の選定基準の策定、契約による安全管理義務の設定。
  • 外的環境の把握：第6条に記載の委託先を通じてアメリカ合衆国において個人データを取り扱うため、同国の個人情報の保護に関する制度を把握したうえで、安全管理のための措置を講じています。

万一、個人データの漏えい等が発生し、ご本人の権利利益を害するおそれが大きい場合には、法令に基づき個人情報保護委員会への報告およびご本人への通知を行います。

第11条（開示・訂正・削除等の請求）

  1. ご本人は、当社に対し、当社が保有する保有個人データについて、利用目的の通知、開示、内容の訂正・追加・削除、利用の停止・消去、第三者への提供の停止、および第三者提供記録の開示を請求することができます。
  2. 請求は、第14条のお問い合わせ窓口宛にメールでご連絡ください。当社所定の書式にてお手続きをご案内します。
  3. 不正な請求を防ぐため、ご登録のメールアドレスからのご連絡であることの確認、または本人確認書類のご提示をお願いする場合があります。代理人による請求の場合は、代理権を証する書面が必要です。
  4. 請求内容を確認のうえ、法令に定める場合を除き、合理的な期間内（原則として2週間以内）に対応し、その結果をご連絡します。法令上開示等の義務を負わない場合には、その旨と理由をご説明します。
  5. 開示の請求については、実費相当の手数料を申し受ける場合があります。手数料が必要な場合は、事前に金額をお知らせします。
  6. なお、店舗プロフィールは管理画面からお客様ご自身で確認・修正・削除いただけます。生成履歴は管理画面で確認でき、削除をご希望の場合は第14条の窓口へご連絡ください。
