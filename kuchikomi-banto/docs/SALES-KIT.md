# クチコミ番頭 販売キット（SALES-KIT）

そのままコピペして使える文面集です。
**主戦場は、運営者が主催する「AI夜会」「AI茶会」**（静岡の経営者・店舗オーナーが集まる招待制イベント）。
広告費をかけず、その場で触ってもらい、その場で申し込んでもらう前提で組んでいます。

---

## 1. 最初の10社を獲るための導線設計

### 1-1. なぜイベント一本で足りるのか

- 参加者は**すでに主催者を信頼している**（初対面の飛び込み営業とは前提が違う）
- 「Googleクチコミへの返信」は、飲食・美容・整体・工務店・塾のほぼ全員が持っている共通の悩み
- **その場で10秒で結果が出る**ので、口頭説明より実演のほうが速い
- 参加者同士が横でつながっているので、1社入ると紹介が連鎖する

目標は明確に：**1回のイベント（参加者15〜20名）で、無料お試し10名・有料申込3社。これを3〜4回で10社。**

### 1-2. イベント当日の時間割（実際にこの順番でやる）

| タイミング | やること | 所要 |
|---|---|---|
| 開始前 | 受付でA4チラシを配る。まだ何も説明しない | — |
| 中盤 | 1分ピッチ（後述の台本を読む） | 1分 |
| ピッチ直後 | デモ（後述の進行台本）。**参加者のお店の実際のクチコミを使う** | 5分 |
| デモ直後 | 「今この場でスマホから触ってみてください」とURLを口頭＋チラシで案内 | 5分 |
| 懇親タイム | 触っている人の横に立ち、生成された文章を一緒に見る | 30分 |
| 懇親の終盤 | 手応えがある人にだけ「今日申し込むと〇〇」と伝えて申込へ | — |
| 翌日 | 参加者全員にLINE/メールで案内（初回案内文） | — |

### 1-3. その場で申し込みまで持っていく3つの仕掛け

**仕掛け1：無料お試しを「その場で使い切らせる」**

無料は3件まで。1件目を主催者がデモで見せ、2件目・3件目を**本人のお店の本物のクチコミ**で試してもらう。
使い切った瞬間に「もっと試したい」が最大化する。ここが申込の山場。

**仕掛け2：店舗プロフィール登録をその場で終わらせる**

「業種・こだわり・NGワード・署名」を懇親タイムに一緒に入力する（3分で終わる）。
**一度登録すると『自分の店の文章』になる**ので、ここを越えた人は残る。逆にここを越えないと、家に帰った後に触られない。

**仕掛け3：14日間無料トライアルを「今日から」始めてもらう**

「今日カードを登録しておくと14日間タダで全部使えます。合わなければマイページから解約できて、1円も請求されません」
→ カード登録のハードルは、**その場で主催者が横にいるとき**が一番低い。翌日以降は一気に下がる。

### 1-4. 最初の10社に必ずやること（ここを手抜きしない）

- [ ] 申し込んだ全員に**翌日**お礼の連絡を入れる
- [ ] 初回1週間で「何件生成したか」を確認し、0件なら電話する
- [ ] トライアル終了3日前に必ずリマインドを送る（後述の文面）
- [ ] 有料化した1か月後に「使ってみてどうですか」を聞き、**その声を次のイベントで実名または業種名で紹介する**
- [ ] 「同じ悩みを持ってそうな知り合いいませんか」と聞く（最初の10社は全員に聞く）

## 3. イベント当日の1分ピッチ台本（逐語）

> そのまま声に出して読める文にしています。**急がず、句点で一拍おく。**
> 所要50〜60秒。スライドは不要。スマホかノートPCを手に持って話す。

```
すみません、1分だけお時間ください。

みなさんのお店に、Googleのクチコミって届きますよね。
あれ、返信されていますか。

……たぶん、今うなずかなかった方のほうが多いと思います。
私も同じでした。

理由ははっきりしていて、返信の文章を考えるのに時間がかかるんです。
特に、低い評価がついたとき。
謝ればいいのか、事情を説明していいのか、
その一文が他のお客さんにも読まれると思うと、手が止まる。

それで、二週間たまって、三か月たまって、
気がついたら返していない、という状態になります。

そこで、クチコミの文章を貼り付けると、
返信文を三案つくるツールをつくりました。
丁寧なやつ、親しみのあるやつ、短いやつ。
十秒です。

Googleとの連携もいりません。
コピーして、ビジネスプロフィールに貼るだけです。

今から実際に、この場でやってみます。
どなたか、お店に来ている低評価のクチコミ、
そのままの文章で構いませんので、見せていただけませんか。
```

**ピッチのときに絶対に言わないこと**

- 「これで売上が上がります」（景表法・優良誤認のリスク。**言わない**）
- 「Googleの検索順位が上がります」（保証と受け取られる。**言わない**）
- 「Google公式のツールです」（事実と異なる。**言わない**）
- 「サクラを増やせます」「良い口コミを増やせます」（自作自演の助長。**言わない**）

**言ってよい言い方**

- 「返信の作成にかかる時間を短くします」
- 「返信を溜めずに済むようになります」
- 「返信の有無をお客さんに見られている、という前提での運用が回るようになります」

## 4. その場で見せるデモの進行台本

**用意しておくもの**

- ノートPCまたはタブレット（スマホだと画面が小さくて周りに見えない）

- 事前に用意した**低評価のサンプル文**（本物が出てこなかった場合の保険）
- 生成済みの結果を1つブックマークしておく（万一APIが遅い/落ちたときの保険）

### 進行（5分）

**【0:00】まず何もしていない画面を見せる**

```

これだけです。設定画面とか、管理画面とか、そういうのは今は出てきません。
```

→ 「シンプルすぎて拍子抜けする」を意図的に作る。**ここで警戒が下がる。**

**【0:30】参加者の本物のクチコミを貼る**

その場で誰かに出してもらう。出てこなければサンプルを使う。

**推奨サンプル（星2・飲食店）**
```

値段を考えると、もう一度行くかは微妙です。
```

これを貼りながら、声に出して読む。**読むことが重要。** 会場が「あー」となる。

```

全部が嘘ってわけじゃない。実際に待たせているし、遅かった。
でも「もう行かない」と書かれている。

**【1:45】3案が出た瞬間 — ここが「おお」と言わせるポイント①**

3案が同時に出る。まず**それだけを黙って見せる**。

```

## 6. チラシ／A4一枚の紙面構成案

**前提**：イベント受付で手渡す。持ち帰って机に置かれ、翌週もう一度目に入ることを狙う。
**印刷**：A4片面、カラー。厚めの紙（90kg以上）。折らない。

### 紙面の構成（上から順に）

**① 最上部（用紙の上から約15%）— 見出し**

- 中央揃え、大きな明朝またはゴシック（36〜40pt相当）
- 文言：**「そのクチコミ、何と返しますか。」**
- その直下、小さめ（14pt）で1行：`Googleクチコミの返信文を、AIが10秒で3案つくります。`
- 装飾はしない。背景色も敷かない。**白地に黒文字。**「安っぽい広告」に見せないことが最優先

**② 上段左（用紙の上から15〜40%、左半分）— 課題の提示**

- 見出し（18pt）：`こんな状態になっていませんか`
- チェックボックス付きで4行（14pt、行間広め）
  - □ 低評価が来たが、何と返せばいいか分からない
  - □ 返信しなきゃと思いながら、数か月たまっている
  - □ 毎回文面を考えるのが正直しんどい
  - □ 返信の有無が評価に影響すると聞いたが、手が回らない
- **参加者が自分でチェックを入れられる余白を残す**（実際に入れてもらうと持ち帰り率が上がる）

**③ 上段右（用紙の上から15〜40%、右半分）— ビフォー/アフター**

- 上に「これまで」：吹き出し風の枠に `1件あたり 10〜15分`
- 下に「これから」：同じ大きさの枠に `1件あたり 10秒`
- 2つの枠の間に下向きの矢印
- **数字だけを大きく**（48pt程度）、単位は小さく。ここが紙面で2番目に目立つ場所

**④ 中段（用紙の中央、40〜62%）— 実物の画面イメージ**

- **ここが紙面の主役。面積を惜しまない**
- 左に「入力したクチコミ」（実際のサンプル文をそのまま小さめの文字で）
- 右に「生成された3案」（丁寧／親しみ／簡潔の3つを、それぞれ短い枠に）
- 中央に太い矢印と `10秒`
- 3案のうち**丁寧案だけ全文を載せ**、他2案は冒頭2行＋「…」で省略する（読ませすぎない）
- 丁寧案の脇に、細い引き出し線で4つの注記
  - 「お詫び」「事実の確認」「改善策」「オフラインへ誘導」
  - この注記が**この紙面でいちばん価値のある情報**。省略しない

**⑤ 中下段（62〜75%）— 3つの特徴を横並び**

- 3カラム均等、各カラムは見出し（16pt太字）＋本文2行（12pt）
  1. `店舗プロフィールを一度登録するだけ` / 業種・こだわり・NGワード・署名を登録すれば、以降すべての返信に自動で反映されます。
  2. `低評価には専用の型` / 謝罪 → 事実確認 → 改善 → 直接お話を、の順に自動で組み立てます。
  3. `返信しないほうがいい投稿を教えます` / 誹謗中傷や事実無根の投稿を検知し、削除申請を助言します。
- アイコンは使わない（使うと途端に安っぽくなる）。**罫線で3分割するだけ**

**⑥ 下段（75〜88%）— 料金**

- 横並び2枠＋左端に「無料お試し」の小さな枠、計3枠
  - `無料お試し` / 登録不要・3件まで
  - `ライト` / **月 2,980円**（税込） / 月100件・1店舗
  - `スタンダード` / **月 5,980円**（税込） / 月500件・5店舗
- 3枠の下に1行、12pt：`どちらも14日間無料でお試しいただけます。いつでも解約できます。`
- **「今だけ」「限定」といった煽り文句は入れない。** 招待制イベントの参加者に対して逆効果

**⑦ 最下部（88〜100%）— 行動導線**

- 左側：QRコード（3cm角以上。小さいと読み取れない）
- QRの下に `https://kuchikomi-banto.jp` をテキストでも記載（QRが読めない人向け）
- 右側：`今この場で、お店に届いた本物のクチコミを1件だけ貼ってみてください。`（14pt）
- その下に主催者の名前・連絡先を小さく（10pt）
- 最下行、8ptで注記：
  `※Googleビジネスプロフィールへの投稿はご自身で行っていただきます。Google LLCとは関係のない独立したサービスです。`

**⑧ 紙面全体のルール**

- 使う色は**黒＋グレー＋差し色1色**まで。差し色は数字と枠線にだけ使う
- フォントサイズの下限は**10pt**。50代の参加者が眼鏡なしで読める範囲を守る
- 余白を詰めない。**空白の面積が3割**あるくらいでちょうどいい
- 「AI」という言葉を紙面で使うのは**見出し下の1行と特徴欄だけ**。連呼すると胡散臭くなる

聞きたいのは、書けるかどうかじゃなくて、

書ける人が3か月分ためている理由は、書けないからじゃなくて、

正直、引き止めの仕組みを作るより、

- 断られたら**あっさり引く**。招待制コミュニティでの評判のほうが1件の契約より重い

## 8. 無料 → 有料の転換施策

### 8-1. 無料3件を使い切った瞬間の見せ方

**やってはいけないこと**
- 「上限に達しました」だけ出して終わり（もっとも多い失敗）
- エラーの赤い画面
- いきなりカード入力画面に飛ばす

**やること：3件目の結果を消さずに、その下に案内を出す**

画面に出す文言（実装済みでなければこの文言に差し替える）：

```
無料でお試しいただける3件を使い切りました。

▼ ここまでで作成した3件の返信文
（3件分をそのまま表示し続ける。消さない。コピーもできるままにする）

続けてお使いいただく場合

  ライトプラン 月2,980円（税込）／ 月100件・1店舗
  ・14日間は無料です。この期間中は1円も請求されません
  ・店舗プロフィールを登録すると、返信文がお店の言葉になります
  ・解約はマイページからいつでもできます

  [ 14日間無料ではじめる ]

  ※クレジットカードのご登録が必要です（トライアル中の請求はありません）
```

**設計上のポイント**
- **作った3件を消さない。** 消すと「取り上げられた」感覚になり、離脱する
- 「上限」より先に「続けて使う方法」を書く
- 「14日間無料」と「1円も請求されない」を**同じ画面に2回書く**（カード登録の心理的ハードルはここで決まる）
- ボタンは1つだけ。プラン選択肢を並べない（迷わせない）

### 8-2. トライアル中の接触タイミング（4回）

| タイミング | 手段 | 目的 | 内容の要点 |
|---|---|---|---|
| **登録直後（即時）** | メール自動送信 | プロフィール登録に誘導 | 「まず3分だけ、業種とこだわりと署名を登録してください。これで文章がお店のものになります」＋設定画面への直リンク |
| **2日目** | メール | 初回利用の確認 | 利用0件なら「使い方でつまずいていませんか」／1件以上なら「低評価のクチコミでも試してみてください」 |
| **7日目（中間）** | LINE or メール（短く） | 定着確認 | 「この1週間で〇件作成されています。ここまでの使い心地はいかがですか」＋一行返信を促す |
| **11日目（終了3日前）** | メール | 継続の意思決定 | 第2章のパターンC。利用件数を必ず入れる |

**利用件数の出し方**

```bash
npx wrangler d1 execute kuchikomi-banto --remote \
  --command "SELECT a.email, COUNT(r.id) AS n FROM accounts a LEFT JOIN replies r ON r.account_id=a.id WHERE a.trial_ends_at IS NOT NULL AND a.trial_ends_at > datetime('now') GROUP BY a.id ORDER BY n ASC;"
```

- **件数が0の人を最優先で追う。** 0件のまま課金が始まると、ほぼ確実に即解約＋悪い印象が残る
- 件数が10件以上の人は放っておいても残る。**声をかけるのは「1〜3件の人」がいちばん効く**

### 8-3. 転換率の目安と、下回ったときの打ち手

| イベント参加者 → 無料お試し | 50%以上 | ピッチではなくデモを長くする。その場でスマホを開かせる |
| 無料お試し → トライアル登録 | 25〜35% | 3件使い切り画面の文言を直す。プロフィール登録をその場でやらせる |

## 9. 価格設定の根拠と、値上げ／値下げの判断基準

### 9-1. なぜ ¥2,980 / ¥5,980 なのか

**¥2,980（ライト）の根拠**

- 中小店舗オーナーが「稟議なしで自分の判断で払える」上限が概ね月3,000円台
- 月100件は、飲食店で月20〜30件の店でも3倍以上の余裕がある。**上限を意識させないことが目的**
- 原価は最悪ケースでも月¥800程度（GO-LIVE.md 10-4参照）。粗利73%
- ¥1,980にしなかった理由：安すぎると「その程度のもの」と受け取られ、かつ手厚いサポートができなくなる
- ¥3,980にしなかった理由：4,000円台に入ると「他と比べる」モードに入り、決裁が1週間延びる

**¥5,980（スタンダード）の根拠**

- 複数店舗を持つオーナー（美容室2〜3店、飲食2店など）向け
- **ライト2契約（¥5,960）とほぼ同額**の¥5,980に置いてある。差額¥20で、店舗数が1→5、月の件数が200→500になる
  - ※「ライト2契約より安い」ではない（¥20だけ高い）。**「安い」と言わないこと。**言うなら「ほぼ同じ金額で、5店舗まで・月500件まで使えます」
- 2店舗持ちなら1店舗あたり実質¥2,990。3店舗以上になると1店舗あたりの単価が下がり続けるので、多店舗のオーナーほど得になる
- 月500件は事実上の使い放題。粗利は最悪ケースで33%まで落ちるが、平均利用では85%以上残る

**2プランしか作らない理由**

3つ以上並べると選択が止まる。「1店舗ならライト、複数店舗ならスタンダード」という**業態で自動的に決まる分け方**にしてある。

### 9-2. 値上げの判断基準

以下が **2つ以上** 同時に成立したら値上げを検討する。

- [ ] 有料契約が **30社以上**、かつ月次解約率が **3か月連続で3%未満**
- [ ] トライアル → 有料の転換率が **70%を超えている**（価格が安すぎるサイン）
- [ ] 「高い」という理由での失注が **直近20商談中2件以下**
- [ ] スタンダードで月400件超のヘビーユーザーが **3社以上**（原価が効いてきている）
- [ ] 機能を追加した（例：一括生成、Googleビジネスプロフィール連携、返信履歴の分析）

**値上げのやり方（既存顧客を裏切らない）**

1. **既存顧客は現行価格のまま据え置く**（グランドファザリング）。これを明言する
2. 新規のみ新価格にする。ライト ¥3,980 / スタンダード ¥7,980 が次の刻み
3. 値上げの1か月前に既存顧客へ告知し、「あなたの価格は変わりません」を件名に入れる
4. 上位プラン（例：プロ ¥12,800/月・2,000件・10店舗）を**追加する形**での実質値上げを先に試す

### 9-3. 値下げ／プラン変更の判断基準

以下が成立したら、値下げではなく**まず原因を特定する**。

| 症状 | 数字の目安 | 本当の原因（多い順） | 打ち手 |
|---|---|---|---|
| 無料は使うが有料にならない | 転換率20%未満 | 価格ではなく**価値が伝わっていない** | 3件使い切り画面と、プロフィール登録の導線を直す |
| 「高い」と言われて失注 | 直近20商談中5件以上 | 業種によって費用対効果が違う | 値下げではなく**より安い下位プラン**（¥1,480・月30件）の新設を検討 |
| 契約するがすぐ解約 | 3か月以内の解約が30%超 | オンボーディング失敗 | トライアル中の接触を増やす。**価格は触らない** |
| 特定の業種だけ全滅 | — | その業種はクチコミの量が少ない | ターゲット業種から外す |

**値下げに踏み切る条件（ここまで来たら）**

- [ ] 上記の打ち手をすべて試して3か月経過
- [ ] それでも転換率が20%を下回り続けている
- [ ] 失注理由の**過半数**が明確に「価格」である

→ この場合も既存価格は下げず、**下位プランを追加**する。既存顧客の値下げは最後の手段。

### 9-4. 解約が出たときの動き方

| 1か月の解約件数（有料30社時点） | 判断 | 動き |
|---|---|---|
| 0〜1件 | 正常 | 理由だけ聞いて記録 |
| 2件 | 許容範囲 | 2件の理由に共通点がないか確認 |
| 3件（10%） | 黄信号 | **新規獲得を止め**、既存全社に電話。使われていない人を洗い出す |
| 4件以上 | 赤信号 | イベント登壇も止める。既存顧客ヒアリングに全振り。原因が判明するまで新規は取らない |

## 10. 営業トークでの表現ルール（誇大広告・景表法・薬機法）

**このセクションは、上のどの文面よりも優先されます。**
イベントの場では口が滑りやすいので、事前に読んでおいてください。

### 10-1. 絶対に言わない・書かない表現

| ❌ 禁止表現 | なぜダメか |
|---|---|
| 「必ず売上が上がります」 | 景表法・優良誤認。効果の保証は不可 |
| 「クチコミの評価が上がります」 | 同上。返信で星の評価が上がる保証はない |
| 「MEOの順位が上がります／保証します」 | 同上。Googleのアルゴリズムは非公開で、保証は不可能 |
| 「Google公式ツールです」「Google認定」 | 事実と異なる。商標・信用の問題 |
| 「Googleと提携しています」 | 事実と異なる |
| 「悪い口コミを消せます」 | できないし、できると誤認させるのは不当表示 |
| 「良い口コミを増やせます」 | 自作自演・サクラの助長。Googleガイドライン違反 |
| 「業界No.1」「日本初」「唯一の」 | 客観的な調査結果がない限り不当表示 |
| 「導入すれば集客が〇%改善」 | 根拠のない数値は不可。実績があっても条件を明示しない限り不可 |
| 「絶対に炎上しません」 | 保証にあたる |
| （整体・接骨院向けに）「症状が改善したという口コミが増えます」 | **薬機法**。効能効果の暗示にあたる |
| （クリニック向けに）「治療効果の高さをアピールできます」 | **医療広告ガイドライン**に抵触するおそれ |

### 10-2. 言ってよい表現（言い換え表）

| 言いたいこと | ❌ NG | ✅ OK |
|---|---|---|
| 効率が上がる | 「売上が上がります」 | 「返信の作成にかかる時間が短くなります」 |
| 評価への影響 | 「評価が上がります」 | 「返信の有無や内容は、投稿を見た方の印象に関わると言われています」 |
| MEO | 「順位が上がります」 | 「Googleビジネスプロフィールの運用を続けやすくなります」 |
| 低評価対応 | 「炎上を防げます」 | 「公開の場で言い合いにならない書き方の型を使っています」 |
| 中傷対応 | 「誹謗中傷を削除できます」 | 「返信すべきでない投稿を検知して、削除申請の検討をお勧めします」（削除の可否はGoogleの判断） |
| 実績 | 「導入店舗〇〇社が効果を実感」 | 「〇〇業の方から『返信がたまらなくなった』という声をいただいています」（実際にもらった声のみ） |

### 10-3. 業種別に特に注意する相手

| 業種 | 注意点 |
|---|---|
| 整体・接骨院・鍼灸 | **薬機法・あはき法**。「治る」「効く」「改善する」を返信文の話題にしない。ツールの説明でも症状改善を連想させない |
| 歯科・クリニック | **医療広告ガイドライン**。「口コミで治療効果をアピール」は不可。ビフォーアフター表現も不可 |
| 美容・エステ | 薬機法。「痩せる」「シミが消える」等の効能表現に触れない |
| 士業（税理士・弁護士等） | 各士業会の広告規程。「必ず勝てる」「必ず節税」等に触れない |
| 不動産 | 宅建業法の広告規制。おとり広告・誇大広告の話題に近づかない |

→ これらの業種の方には、**「返信文の中に効能効果を書かないように、NGワード機能で設定しておきましょう」** と提案するのが正解。それ自体が付加価値になる。

### 10-4. 事実ベースで言い切ってよいこと（安全な武器）

これらは実装されている事実なので、堂々と言ってよい。

- 「丁寧・親しみ・簡潔の3案が出ます」
- 「Googleアカウントとの連携は不要です」
- 「登録なしで3件まで試せます」
- 「店舗プロフィールを一度登録すれば、以降の全ての返信に反映されます」
- 「低評価には、謝罪→事実確認→改善→オフライン誘導 の順で組み立てます」
- 「誹謗中傷と判断した投稿には返信文を作らず、削除申請を助言します」
- 「14日間無料で、いつでも解約できます」
- 「月額2,980円（税込）です」

### 10-5. 迷ったときの原則

- **「〜します」（機能の説明）はOK。「〜になります」（結果の約束）はNG。**
- 数字を出すなら、**必ず出典か実測条件をセットで**言う
- お客様の声を使うときは、**実際にもらったものだけ**を、**その人の許可を得て**使う
- 断定できないことは「〜と言われています」「〜という声をいただいています」に留める
- **迷ったら言わない。** 招待制コミュニティでの信用は、1件の契約より重い
